# Study AI 2.0 (With Export Feature)

과목별 학습 기록을 바탕으로 성적 참고 추정, 학습 전략 피드백, 시험일까지의 반응형 플랜 및 CSV 저장 기능을 제공하는 Streamlit 웹앱입니다.

## 실행 방법
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 주요 기능 및 최적화
- **스터디 플래너 CSV 다운로드**: 웹 페이지 이탈 시 데이터 소실을 방지하기 위해 생성된 날짜별 계획표를 CSV 파일로 저장
- **모바일 반응형 CSS 적용**: 스마트폰 화면 접속 시 7열 달력 카드가 1열 세로 카드로 자동 변환
- **전체 진단 총평 메트릭**: 전략 탭 상단에 취약/발전/안정 과목 개수 요약
- **성적 및 커스텀 과목 입력**: 사용자 과목 자유 추가 가능
- **Radar Chart 시각화**: 과목별 정답률 및 개념 이해도 한눈에 비교
